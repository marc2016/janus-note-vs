# Janus Note for VS Code

Janus Note pairs human-readable Markdown notes with machine-operable, schema-validated companion files (`*.tasks.json`, `*.chart.json`).

## Features

- **Companion Discovery & CodeLens**: Automatically pairs notes with companion task and diagram files.
- **Visual Task Board**: Interactive Kanban / Checklist view for `*.tasks.json`.
- **Diagram View**: Interactive Mermaid diagram viewer for `*.chart.json`.
- **VS Code Language Model Agent (@janus)**: Native chat participant and language model tools for reading notes and mutating companions safely.
