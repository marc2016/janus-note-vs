# CLAUDE.md

## Commits

- Short one-line commit messages in conventional style (`feat: ...`, `fix: ...`, `chore: ...`), matching the existing history.
- Never add a `Co-Authored-By` line or any other attribution trailer.

## Ideas

- Ideas for future OpenSpec changes (bugs and features) are collected in `openspec/IDEAS.md`. Add new ideas there, and remove an entry once it has become a change.
